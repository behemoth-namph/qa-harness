# Thư mục spec

Đặt toàn bộ tài liệu spec của dự án vào đây (có thể chia thư mục con theo module).
Định dạng hỗ trợ: `.md`, `.txt`, `.csv`, `.docx`, `.pdf`, `.xlsx`.

- Tài liệu chỉ được đọc cục bộ, không gửi ra dịch vụ bên ngoài.
- Không để mật khẩu, token, khóa API, dữ liệu khách hàng thật trong thư mục này.
- Thư mục này chứa thông tin nội bộ: không đưa lên kho mã công khai.
